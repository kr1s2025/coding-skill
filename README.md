# coding-skill

My custom skills for Claude Code, Codex, and Antigravity.

## Skills

- `sum`: shortens a long answer or review report on demand (`/sum`).
- `explain`: explains a concept, system, or topic so you actually understand it.
- `frontend-design`: builds distinctive, polished web and UI interfaces.
- `unslop`: cleans up AI-sounding writing in documents meant for other people.

## Install

Copy a skill folder into your skills directory:

- Claude Code: `~/.claude/skills/<skill>/`
- Codex: `~/.codex/skills/<skill>/`
